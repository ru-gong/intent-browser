MVP Operator Handbook

给 Agent 调试页面的专用浏览器。

它不是普通预览窗口，而是一层能理解 DOM、空间坐标和用户意图的操作界面。用户在页面上改字、改图、拖拽布局、插入批注，Agent 立即收到结构化 Diff Payload。

0 build 浏览器只采集和回传 Diff，代码重构与编译留在 Agent 侧。

三种模式，语义不同，页面不刷新。

模式切换只改变 target preload 内部的运行时状态和遮罩行为。目标页面保持原有路由、前端状态和滚动位置，用户操作被转译成 Agent 可读的差异事件。

01

常规预览

像普通浏览器一样查看页面，但保留 CLI、RPC 和模式切换能力。

  • 页面正常点击、滚动、输入。
  • overlay 隐藏，不劫持用户事件。
  • 适合 Agent 生成后的第一眼检查。
02

快捷编辑

面向 WYSIWYG 反馈：改文本、改图片链接、调整常用 CSS 数值、拖拽元素。

  • 双击文本进入纯文本 contenteditable。
  • 图片和背景图可直接替换 URL。
  • 样式变更生成 before / after Diff。
03

批注插入

用户在任意元素或区域打点，写下修改意见，形成空间锚定反馈。

  • 点击即生成可保存气泡。
  • payload 包含 viewport / page / element 坐标。
  • 适合设计审阅和精确重构指令。

运行时拆成三个清晰边界。

主进程负责窗口编排、RPC、CDP 增强和事件持久化；目标页面只接收隔离 preload；工具栏和 payload 面板在独立 WebContentsView 里渲染。

CLI / Agent 启动 GUI、切换模式、读取事件、订阅 JSON-RPC 通知。
Electron Main SessionBus、AgentRpcServer、WebContentsView 布局。
Target Preload 隔离世界内捕获事件，封闭 Shadow DOM 渲染遮罩。
CDP DOM 用 DOM.getNodeForLocation 补充 backendNodeId。
Diff Payload selector、XPath、source metadata、坐标、具体 change。

Agent 通过 CLI 无门槛接入。

所有关键操作都能从命令行完成；GUI 是给人类查看和操作的界面，CLI 是给 Agent 拉取状态和消费 Diff 的界面。

启动页面

打开本地 HTML 或远程 URL，并把用户操作追加写入 NDJSON。

node bin/intent-browser.js docs/intent-browser-guide.html --port 17345 --out ./diffs.ndjson

读取交互

Agent 可轮询 JSON，也可以用 NDJSON 直接做流式消费。

node bin/intent-browser.js read --port 17345 --since 0 node bin/intent-browser.js read --port 17345 --format ndjson

切换模式

无需刷新目标页面，命令发出后主进程通过 IPC 通知 target preload。

node bin/intent-browser.js mode quick-edit --port 17345 node bin/intent-browser.js mode annotation --port 17345

查看状态

用于确认当前 URL、事件数量、最近模式切换延迟和 session id。

node bin/intent-browser.js snapshot --port 17345 node bin/intent-browser.js --help

Payload 不是截图描述，是可执行定位。

Agent 收到的不是“左上角那个标题”这种自然语言猜谜，而是多层定位信息与明确 change。即使 selector 失效，也能用 XPath、DOM path、source metadata 或 CDP backend id 回退。

字段解剖

同一个事件会带上页面、目标、变更、交互和来源。目标字段刻意冗余，是为了跨框架、跨组件树、跨生成器都能被 Agent 识别。

字段用途
target.cssSelector首选定位，优先使用 id、data-testid、aria-label 等稳定属性。
target.xpath结构回退，适合没有稳定属性的静态页面。
target.source显式 data-source、React/Vue 调试信息、最近祖先组件元数据。
target.cdpChromium DevTools Protocol 返回的 backend node 信息。
interaction.pointviewport / page 坐标，用于空间锚点和视觉重构。
change文本替换、图片链接、样式数值或批注意见。

Editable target

把这里当成 Agent 生成页面上的真实标题。

这段文字适合测试 Quick Edit：双击后输入新文案，失焦时应生成 text.replace payload；点击这里插入批注，应生成 annotation.create payload。

  • CLI 执行 mode annotation 后，工具栏高亮切到批注模式，侧栏状态同步更新。
  • 点击左侧标题并保存批注后，侧栏 Events 计数加一，CLI read 能读到同一事件。
  • payload 里应包含 data-testid、XPath、source ancestor 和 CDP backendNodeId。
  • 退出模式不刷新页面，不丢失滚动位置，不破坏页面原始布局。
